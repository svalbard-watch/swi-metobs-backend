# Privacy Policy

> **Placeholder.** This instance of the software has no privacy policy configured.

The operator of this instance must publish their own privacy policy. To do so, set the
`SWI_LEGAL_REPO` environment variable of the metobs backend to a GitHub repository (`owner/repo`)
that publishes releases tagged `privacy-policy-vX.Y.Z` containing `privacy_policy_EN.md`.

Until then, no statement is made here about how personal data is handled.
